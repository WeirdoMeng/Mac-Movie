# 摸鱼视界

macOS 原生观影客户端，使用 SwiftUI + AVKit，通过北觅公开页面读取内容，无 WebView、无第三方运行时依赖。

## 已实现

- 发现、电影、连续剧、综艺、动漫、纪录片、动画片、短剧和最近更新。
- 分类、地区、年份、语言、字母筛选，以及最新、最热、评分排序；具体选项使用网站实际返回的数据。
- 关键词搜索、分类及搜索滚动到底自动加载下一页；总榜、月榜、周榜和榜单内分类。
- 海报、网站评分、更新状态、详情、剧情简介、演员信息和相关推荐。
- 本机收藏、观看历史、移除和清空历史、断点续播。
- 原生播放、进度拖动、前进/后退 10 秒、暂停、音量、静音、全屏及原生媒体选择菜单。
- 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 倍速、上一集/下一集、选集倒序、多线路同集切换及进度保留。
- 自动下一集，可关闭；最后一集或关闭自动连播时播放结束后停留本集，并支持重新播放。
- 浏览片库时保留播放，底部显示播放入口；收藏、历史、音量、静音、倍速及连播偏好在本机持久保存。
- 窗口全屏仅铺满当前窗口；系统全屏单独提供。
- 无边框、窗口置顶、整窗不透明度 10%～100%、自由缩放及窗口位置保存。
- 每次启动默认 299×531 点的小窗口（以用户当前无边框窗口为准）；手动缩放时自动切换紧凑布局与桌面侧栏布局。
- 小窗口保留搜索、横向分类、海报网格与详情；不会自动切换为纯播放器。
- 18 个操作快捷键可自定义、清除和恢复默认，修改立即生效；全局显隐采用 Carbon 热键，冲突时保留原绑定。
- 小窗口分类栏支持普通鼠标纵向滚轮横向浏览，触摸板保持原有手势；隐藏滚动条但保留滚动。
- 顶部仅保留“摸鱼视界 / 播放 / 窗口”三个中文菜单。
- 请求失败、验证页、解析失败和播放失败提示；播放准备超过 45 秒可重试。

## 运行与构建

要求 macOS 13+，源码构建要求 Swift 5.9+。本机已生成 Apple Silicon 版本：

```bash
bash scripts/build-app.sh
open 'dist/摸鱼视界.app'
```

分发安装包可运行 `bash scripts/package.sh`，生成 `dist/摸鱼视界-0.3.3-arm64.pkg`（双击按向导安装到应用程序）和同名 DMG（拖拽安装）。仅支持 Apple Silicon，macOS 13+。当前使用本地 ad-hoc 应用签名，安装包没有 Developer ID 签名和 Apple 公证，其他电脑可能出现安全提示。

在左侧选择分类或收藏/历史；右上角搜索；点击海报进入详情并选择集数。历史卡片直接继续上次观看。点击返回或其他分类时播放继续，可使用底部“返回播放”回到影片。

播放进度每 5 秒保存一次，暂停、切集、停止及退出时保存。完成一集后再次进入会从头播放。历史保留最近 200 部影片。

默认快捷键按用户 2026-10-20 当前保存的配置设置；“恢复默认”也使用此配置。设置入口为 `⌘,`，修改立即生效，无需重启。

| 操作 | 默认快捷键 |
| --- | --- |
| 全局显隐 | Control+4 |
| 窗口全屏 | Control+Option+F |
| 无边框 / 置顶 | Command+Shift+B / Command+T |
| 提高 / 降低不透明度 | Control+= / Control+- |
| 放大 / 缩小窗口 | Command+= / Command+- |
| 播放或暂停 | 空格 |
| 后退 / 前进 10 秒 | ← / → |
| 上一集 / 下一集 | Command+← / Command+→ |
| 静音 / 停止 | Command+Shift+M / Command+Shift+S |
| 搜索 / 设置 | Command+F / Command+, |
| 系统全屏 | Control+Command+F |

输入框中空格、方向键继续用于输入。窗口全屏时 Esc 返回浏览布局。无边框时可拖动顶部区域移动窗口，右下角可自由缩放。仅“全局显隐”在其他应用获得焦点时也生效。隐藏窗口会自动暂停并保存进度，再次显示保持暂停，需手动播放；加载期间隐藏也会禁止就绪后自动起播。打开新版前请退出旧版或测试预览，避免显隐热键被旧进程占用。

## 验证命令

```bash
bash scripts/test.sh
.build/release/MacMovie --window-check
.build/release/MacMovie --audit
.build/release/MacMovie --probe
```

- `--check`（由测试脚本执行）：离线验证解析、分页、播放顺序、线路匹配、续播条件、收藏/历史/设置保存及损坏记录恢复。
- `--window-check`：使用独立偏好和临时热键验证窗口全屏、无边框、透明度、置顶、自由缩放、全局热键注册与冲突回退、中文菜单及菜单快捷键刷新；小窗口测试渲染保存到 `dist/compact-home.png`。
- `--audit`：实际读取首页、连续剧筛选、分类第二页、搜索第二页、日本地区筛选、最近更新及总/月/周排行。
- `--probe`：使用独立临时偏好，真实播放《嫁金钗》，验证 30 秒起播、跳到 90 秒、暂停与进度保存、续播、1.5 倍速、视频帧解码、手动下一集、自动下一集开/关及播完重播。完成后删除该测试偏好，不修改应用的正式收藏和历史。帧保存到 `dist/probe-frame.png`。

网络验证依赖站点和 CDN 可用性；不代表所有影片、线路和长期播放都已覆盖。声音输出和不同显示器的全屏效果需要实际设备听看确认。

## 数据与边界

本机数据位于应用偏好域 `local.macmovie.demo` 的 `macmovie.library.v1`，不与网站账号同步。损坏数据会保留一份 recovery 备份，然后允许继续使用。收藏和历史保存影片及选集信息，不保存临时媒体 URL；每次开始播放重新取得地址。

本轮范围为观影功能，不包含网站登录、评论、求片、商城、离线下载或外部字幕管理。AVKit 的媒体菜单仅在资源提供对应音轨/字幕时显示可选项。不会绕过网站验证或 DRM。网页结构改变、源站限制、编码不受系统支持时可能无法播放。

页面提供的评分、年份和更新状态不代表资料准确性。公开分发或商业接入前需要相应内容及数据使用授权。

## 源码

- `Beimi.swift`：站点适配、目录/筛选/分页/详情解析与播放地址。
- `Library.swift`：浏览与播放状态、异步任务取消、进度保存及自动切集。
- `LocalLibrary.swift`：本机持久化、播放顺序与续播策略。
- `Views.swift`、`DetailView.swift`：原生片库、详情、播放器和设置。
- `DesktopController.swift`、`WindowViews.swift`、`Shortcuts.swift`：窗口控制、响应式布局、即时设置、中文菜单和快捷键。
- `Checks.swift`、`ShortcutChecks.swift`、`Probe.swift`：离线回归与真实网络/播放验证。
